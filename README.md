# 291 Group Scoop bucket

Scoop manifests for 291 Group's open source tools.

    scoop bucket add 291group https://github.com/291-Group/scoop-bucket

## LAN Orangutan

Network discovery and device inventory for your LAN.

    scoop install lan-orangutan

Needs nmap, including Npcap. Install it from nmap.org first.

## LAN Sheriff

Watches which servers your network talks to.

    scoop install lan-sheriff

Both are published automatically by each project's release workflow.
